# Calculadora segura

## Archivos
- `main.py`: inicia el programa.
- `calculadora.py`: menú, validaciones, función `calcular()` y propagación.
- `operaciones.py`: operaciones matemáticas y conversión de texto a número.
- `historial.py`: lista global y visualización del historial.

## Ejecución
Coloque los cuatro archivos `.py` en la misma carpeta y ejecute:

```bash
python main.py
```

## Pruebas sugeridas
- División: escriba `10` y `0` para probar `ZeroDivisionError`.
- Promedio: presione Enter sin números para probar lista vacía.
- Entrada numérica: escriba `hola` para probar `ValueError` y la repetición.
- Raíz: escriba `-9` para probar `ValueError`.
- Propagación: elija la opción 7.
- Historial: elija la opción 8.
